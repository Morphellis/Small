# СМОЛ (Мини-Мульт) — тренажёр

Статический сайт: 71 вопрос, шкалы, профиль и регистрационный лист пересчитываются после каждого ответа.
Сборка и сервер не нужны: достаточно открыть `index.html` в браузере (или выложить папку на любой статический хостинг).

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html`, `styles.css` | разметка и оформление (светлая и тёмная тема по системе) |
| `app.js` | интерфейс: вопросы, таблица, SVG-график, лист, кнопки, клавиатура |
| `scoring.js` | весь подсчёт, без DOM (работает и в Node) |
| `data.js` | вопросы, ключи, поправки K, нормы |
| `tests/scoring.test.js` | юнит-тесты (`npm test` или `node --test`) |

## Управление

- Клик по «Да / Нет / Не знаю»; повторный клик по выбранному ответу снимает его.
- Клавиатура: `1` Да, `2` Нет, `3` Не знаю (курсор сам переходит к следующему вопросу), `0` или `Backspace` снять, `↑ ↓` выбрать вопрос.
- Под вопросом, на который ответили последним, видно, какие шкалы он изменил (например, `K +1 · 1 +1 (поправка K)`).
- Кнопки «График» и «Таблица» сворачивают части панели; если таблица свёрнута, вместо неё видна компактная полоска Т-баллов. На телефоне так и есть по умолчанию.
- Ответы хранятся в браузере (переживают перезагрузку). Кнопка «Сбросить результаты» очищает ответы и историю.

## Подсчёт как на psytests.org

- **Ключ** (`scales` в `data.js`) восстановлен по 14 прогонам теста на psytests.org, результаты совпадают с их сырыми баллами по всем 11 шкалам. От классического ключа из ТЗ (`scalesClassic`) отличаются шкалы 2, 8 и F, подробности в комментарии в `data.js`. Переключатель: `KEY_VARIANT` в `scoring.js`.
- **Поправка K** по таблице бланка, но у psytests при K = 5 к шкале 1 прибавляется 2, а не 3 (`kCorrectionPsytests`).
- **Т-баллы** по профильным листам Козюли (`profileSheets`). Мужской лист выверен по тем же прогонам psytests, женский снят со скана (±1 Т). Формула `T = 50 + 10·(X − M)/SD` включается константой `T_METHOD = "formula"`.

Настройки в `scoring.js`: `K_CORRECTION_MODE` (`"table"` или `"formula"` для `round(k·K)`), `VALIDITY_LIMITS` (результат недостоверен при сыром L > 4 или F > 6), `THRESHOLDS` (71 / 39).

Тренировочный инструмент, не психодиагностика.
