# Изучение вопросов по шкалам в Telegram

Команды `/start`, `/help`, `/app`, `/learn` и `/scales` открывают меню. Для изучения доступны СМОЛ, СМИЛ и ММИЛ. Кнопка «Открыть тренажёр» сохраняет доступ к полному приложению, включая тест Люшера.

После выбора теста и шкалы бот показывает вопросы по порядку их номеров в опроснике. В режиме изучения ответ по ключу виден сразу. В режиме самопроверки он появляется после ответа «Да» или «Нет». Пояснение относится к начислению сырого балла выбранной шкалы, без поправки K и перевода в Т-баллы. Один пункт может входить в разные шкалы с разными ключами.

Кнопки «Назад», «Далее», «Выбрать шкалу», «Выбрать тест» обновляют одно сообщение. Позиция и режим хранятся в данных кнопок; отдельная БД не требуется. Каждое сообщение является самостоятельной учебной сессией. Накопительный счёт правильных ответов и перенос позиции в новое сообщение не реализованы. Учебные ответы не изменяют прохождение в мини-приложении.

## Настройка Cloudflare

Production Worker `small` должен иметь два секрета:

- `TELEGRAM_WEBHOOK_SECRET` — секрет входящих обновлений Telegram;
- `TELEGRAM_BOT_TOKEN` — токен бота для редактирования сообщений.

Токены не добавляются в Git, wrangler.jsonc или клиентскую сборку. После публикации кода нужно один раз вызвать `POST /api/telegram/setup`, передав `Authorization: Bearer <токен бота>` либо заголовок `X-Telegram-Bot-Api-Secret-Token` с серверным секретом. Этот маршрут регистрирует webhook на том же домене, сохраняет действующий серверный секрет и подписывает его на `message` и `callback_query`. Ответ `{"ok":true}` означает, что Telegram принял настройку. Ошибки Bot API и URL с токеном в ответы не выводятся.

Раздел реализован в server/telegramTraining.ts, обработчик — server/telegram.ts; маршруты подключены в server/worker.js. Обычный Node-сервер server/main.ts пока не подключает Telegram-маршруты: для собственного сервера потребуется адаптер. Эти инструкции относятся к Cloudflare.

## Проверка

1. Отправить боту `/learn`.
2. Выбрать каждый из трёх тестов и шкалу.
3. Проверить первый и последний вопросы, переходы вперёд и назад.
4. Включить самопроверку, выбрать оба ответа, убедиться в показе соответствующего ключа.
5. Открыть полное приложение и убедиться, что его сохранённые ответы не изменены.

Автоматические проверки перебирают все вопросы всех шкал трёх опросников, сверяют текст и ответ с серверными ключами, проверяют границы и длину callback_data. Отдельно проверяются авторизация, чужие нажатия, повторные нажатия и ошибки Telegram.

## Отдельное развёртывание ветки BotsFeature9nov

Для этой ветки используется Worker `small-botsfeature9nov`, конфигурация `wrangler.bots.jsonc`.

Команда сборки: `npm run build:cloudflare`.
Команда публикации: `npx wrangler deploy --config wrangler.bots.jsonc`.
Production branch отдельного Worker: `BotsFeature9nov`. Основной Worker `small` продолжает собираться из `main`.

Секреты TELEGRAM_BOT_TOKEN и TELEGRAM_WEBHOOK_SECRET задаются отдельно для каждого Worker. После настройки `/api/telegram/setup` webhook существующего бота будет указывать на новый Worker. Кнопка полного тренажёра продолжает открывать основной сайт small.morphellis.workers.dev.
