# Изучение шкал в Telegram

Рабочая ветка: `BotsFeature9nov`. Worker: `small-botsfeature9nov`. Основная ветка `main` и сайт `small.morphellis.workers.dev` развиваются отдельно.

Команды `/start`, `/learn`, `/scales`, `/help` и `/app` отправляют HTML-виджет Telegram с вкладками СМОЛ, СМИЛ и ММИЛ. Выбор шкалы открывает отдельное Mini App `study` того же бота. Вопросы и ключи отображаются на нашей веб-странице. Старые callback-кнопки переводят пользователя на новый экран вместо продолжения опроса в сообщениях.

Команда `/start` сначала отправляет согласованный текст отдельным сообщением, затем HTML-карточку. В текстовом сообщении и под карточкой остаются кнопки открытия обычного тренажёра и прямого входа в изучение каждого теста для клиентов без поддержки виджетов.

## Ссылки

- Основной тренажёр: `https://small.morphellis.workers.dev/`.
- Именованное Mini App: `https://t.me/odinochnayaPalata_bot/study`.
- Пример открытия конкретного пункта: `https://t.me/odinochnayaPalata_bot/study?startapp=study_smol_L_5`.
- Прямая ссылка в браузере: `https://small-botsfeature9nov.morphellis.workers.dev/#study/smol/L/5`.

Число в ссылке — исходный номер пункта опросника, а не позиция внутри подборки. Telegram передаёт startapp через GET-параметр tgWebAppStartParam. Эти данные используются только для навигации, не для авторизации или определения личности.

## Экран изучения

Отображаются только вопросы выбранной шкалы, в порядке номеров опросника. В режиме «Изучение» ответ по ключу показан сразу. В режиме «Самопроверка» он появляется после ответа. Доступны переходы назад/вперёд и выбор шкалы и вопроса. Ответ по ключу означает начисление сырого балла, без поправки K и перевода в Т-баллы.

Учебный режим не записывает ответы в сохранение полного теста. Основное Mini App и кнопка «Открыть тренажёр» сохраняют прежний домен, поэтому прежний прогресс остаётся на месте. Для учебного раздела регистрируется отдельный short name `study`, основной URL в BotFather не заменяется.

## Развёртывание

Build: `npm run build:cloudflare`.
Deploy: `npx wrangler deploy --config wrangler.bots.jsonc`.
Cloudflare Production branch: `BotsFeature9nov`; сборки других веток отключены.

В Worker нужны секреты `TELEGRAM_WEBHOOK_SECRET` и `TELEGRAM_BOT_TOKEN`. Для регистрации вебхука вызывается `POST /api/telegram/setup` с `Authorization: Bearer <токен бота>` либо заголовком `X-Telegram-Bot-Api-Secret-Token`. Токены не хранятся в Git и клиентской сборке. Node-версия поддерживает API учебного режима; Telegram-вебхук пока подключён только в Cloudflare-адаптере.

В BotFather через `/newapp` создаётся раздел «Изучение шкал» с URL `https://small-botsfeature9nov.morphellis.workers.dev/` и short name `study`.

## Проверка

Модульные тесты проверяют все вопросы и ключи шкал, обработку неверных ссылок, ограничения размера виджета и ссылки запуска. Браузерные тесты проверяют конкретный пункт, границы навигации, самопроверку, ошибки сети, смену шкалы и сохранность ответов полного теста. Виджет тестируется в HTML-стенде; нативное отображение дополнительно проверяется в Telegram.

На 14.11.2026 Telegram отклоняет sendWidget для этого бота с INPUT_MEDIA_WIDGET_NOT_ALLOWED. Ограничение обычных ботов подтверждено разработчиком Telegram: https://github.com/tdlib/telegram-bot-api/issues/947. Рабочий путь: /start → тест → шкала → Mini App. При восстановлении доступа HTML-карточка отправится дополнительно; меню остаётся доступным независимо от неё.
