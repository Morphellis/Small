## Исправление

На каждый HTTP-запрос установлен тайм-аут 10 секунд. Он действует до окончания чтения JSON, а не только до получения заголовков. Зависший fetch отменяется через AbortController. Механизм повторов отправляет актуальные ответы. Отмена при уходе с экрана сохраняется. Таймер и обработчик родительского abort удаляются в finally. Используется краткое сообщение «Сервер не ответил вовремя.»; новые информационные блоки и рекламные формулировки не добавлены.

Остальной прогон покрывает оба предыдущих приёмочных набора и регрессии, включая полное прохождение полного Люшера, перенос ответов между независимыми контекстами, конфликт вкладок, недоступное хранилище и мобильную компоновку.

## Решение

AT2-01 закрыт для проверенной локальной версии. Новых дефектов в выполненном прогоне не обнаружено. По проверенным функциям версия пригодна для ограниченного публичного запуска после публикации исправления.

Готовность к массовому запуску не подтверждена: не проведены проверки на физических Android/iPhone в Telegram WebView и нагрузочная проверка production Worker под ожидаемую аудиторию. Бесплатный тариф оставлен по решению владельца; его ограничение суточного объёма не устранено этим исправлением. Эмуляция WebKit не равнозначна проверке Telegram на iPhone. Firefox в этот прогон не входил. Проверки API не являются независимой проверкой клинических норм.

Опубликованный сайт пока содержит предыдущую версию. Результаты этого отчёта относятся к локальной сборке, а не к исправлению, уже установленному в production.
